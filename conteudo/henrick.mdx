## Como trabalho

Uso agentes de IA no dia a dia (Claude Code e GitHub Copilot), sempre com revisão humana antes de cada mudança ir ao ar.

- **Git com pull requests:** mudanças pequenas, em branches, revisadas antes do merge.
- **Testes em camadas:** Vitest para regras e validações, pgTAP para as regras de acesso do banco e Playwright com axe para o fluxo no navegador e a acessibilidade.
- **Deploy na Vercel**, com uma versão de prévia para revisar cada mudança antes da produção.

Neste site, a segurança veio desde o desenho:

- **RLS em todas as tabelas** do banco, com testes pgTAP que garantem as regras de acesso.
- **CSP e cabeçalhos de segurança**, com teste automático que confere zero violações da CSP em cada página.
- **Logs sem dados pessoais:** nome, e-mail e telefone de quem preenche um formulário nunca vão para os logs nem para o monitoramento de erros.
- **CI com scan de segredos:** o CI falha se encontrar uma chave secreta no repositório.
